# Блокировщик спама (SpamBlocker)

Android-приложение (Kotlin + Jetpack Compose) для блокировки мошеннических звонков. Работает **полностью без интернета**.

## Возможности

- Блокировка звонков через системный `CallScreeningService` (Android 10+)
- Гибкая реакция: **BLOCK** (сброс) или **WARN** (беззвучный + heads-up уведомление)
- 7 правил с приоритетом: белый список → контакты → чёрный список → предзагруженная база → скрытые номера → подозрительные префиксы → нестандартная длина
- В один тап «Это мошенник» / «Это не спам» прямо из журнала или уведомления
- Локальная БД (Room), настройки (DataStore), предзагруженный CSV со спам-номерами
- UI на русском (Jetpack Compose + Material 3)

## Требования

- **Android Studio** Hedgehog или новее (2023.1+)
- **JDK 17**
- Устройство или эмулятор с **Android 10 (API 29)** или новее

## Как собрать

### Вариант 1 (рекомендуется): Android Studio

1. Откройте Android Studio.
2. **File → Open** → выберите папку `c:\Users\Redmi\CascadeProjects\windsurf-project`.
3. Android Studio сама скачает Gradle, SDK, зависимости (первый раз ~5–10 минут).
4. После синхронизации нажмите **Run ▶** (Shift+F10). Выберите устройство/эмулятор.

> Android Studio автоматически создаст недостающий `gradle-wrapper.jar`. Ничего делать вручную не надо.

### Вариант 2: командная строка

Если установлен системный Gradle (8.5+):

```powershell
# из папки проекта, один раз — сгенерировать wrapper
gradle wrapper

# сборка debug APK
.\gradlew.bat assembleDebug

# установка на подключённое устройство
.\gradlew.bat installDebug

# запуск тестов
.\gradlew.bat test
```

APK появится в `app\build\outputs\apk\debug\app-debug.apk`.

### Вариант 3: установка готового APK

После сборки скопируйте `app-debug.apk` на телефон и установите (разрешите установку из неизвестных источников).

## Первый запуск

1. При первом запуске откроется **экран онбординга**.
2. Выдайте разрешения по шагам: **Контакты → Журнал звонков → Уведомления**.
3. На последнем шаге система попросит назначить приложение **«Приложением для определения номера и фильтрации вызовов»** — согласитесь.
4. Готово! Теперь входящие звонки проходят через фильтр.

## Как проверить, что работает

- Зайдите в **Правила фильтрации** → включите «Короткие номера (1–6 цифр)» → выставьте «Блокировать».
- Попросите кого-нибудь позвонить с номера длиной меньше 7 цифр (короткий номер) — звонок будет автоматически сброшен, появится запись в журнале.
- Или добавьте реальный номер в **Чёрный список** и позвоните с него — звонок должен быть заблокирован.

## Известные ограничения

- **Android 9 и старше — не поддерживается** (`minSdk = 29`).
- Только **одно** приложение может быть фильтром звонков. Если уже назначен Truecaller/Яндекс.АОН — его надо снять.
- На Xiaomi/Huawei/Oppo — отключите оптимизацию батареи для приложения, иначе сервис может засыпать.

## Структура

```

├── SpamBlockerApp.kt        — Application, импорт CSV
├── MainActivity.kt          — точка входа UI
├── service/                 — CallScreeningService
├── domain/detector/         — движок правил (SpamDetector)
├── data/                    — Room БД, DataStore, репозитории
├── notification/            — heads-up уведомления
├── ui/                      — Compose-экраны
└── util/                    — PhoneNormalizer, RoleManagerHelper
```
